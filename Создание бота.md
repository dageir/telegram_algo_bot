# Создание бота
> **Цель:** Написать работающего бота, который отвечает на команду `/start`.

---

## 1️⃣ Подготовка

### 🤖 Получение токена

1. Открой в Telegram бота **@BotFather**.
2. Отправь команду `/newbot`.
3. Придумай имя (видят пользователи) и юзернейм (должен заканчиваться на `bot`).
4. **Скопируй токен** (длинная строка символов).
    
    > ⚠️ **Важно:** Никогда не показывай токен посторонним! Как ключ от квартиры.
    

### 💻 Установка библиотеки

Открой терминал (командную строку) и введи:

bash

pip install pyTelegramBotAPI

## 2️⃣ Шаблон кода (main.py)

Создай файл `main.py` и вставь этот код:

```python
import telebot

# Вставь сюда свой токен от BotFather
TOKEN = '123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw'

bot = telebot.TeleBot(TOKEN)

# Обработчик команды /start
@bot.message_handler(commands=['start'])
def start_message(message):
    bot.send_message(message.chat.id, 'Привет! Я твой первый бот 🤖')

# Обработчик любого текста
@bot.message_handler(content_types=['text'])
def text_message(message):
    bot.send_message(message.chat.id, 'Я получил твоё сообщение: ' + message.text)

# Запуск бота
print('Бот запущен...')
bot.polling(none_stop=True)
```

## 3️⃣ Разбор команд 🧐

|Строка кода|Что делает?|
|---|---|
|`import telebot`|Подключает библиотеку для работы с Telegram.|
|`telebot.TeleBot(TOKEN)`|Создаёт «мозг» бота, привязывая его к твоему токену.|
|`@bot.message_handler(...)`|**Декоратор.** Говорит боту: «Слушай сообщения такого типа».|
|`def start_message(...)`|**Функция.** То, что бот сделает, когда услышит команду.|
|`message.chat.id`|Уникальный номер чата с пользователем (куда отвечать).|
|`bot.polling()`|**Главный цикл.** Бот постоянно спрашивает сервер: «Есть новые сообщения?».|

---

## 4️⃣ Как запустить и проверить ✅

1. Запусти скрипт в редакторе кода (зелёная кнопка Play).
2. В консоли должно появиться: `Бот запущен...`
3. Зайди в своего бота в Telegram.
4. Нажми **/start** или напиши любой текст.
5. Бот должен ответить!

> 🛑 **Как остановить бота?**  
> В терминале нажми комбинацию клавиш `Ctrl + C` (или красный квадрат в IDE).

---

## 5️⃣ Частые ошибки 🆘

|Ошибка|Причина|Решение|
|---|---|---|
|`Unauthorized`|Неверный токен|Проверь, скопировал ли токен целиком из BotFather.|
|`IndentationError`|Пробелы в коде|В Python отступы важны! Проверь, чтобы код внутри функций был сдвинут вправо.|
|Бот не отвечает|Скрипт не запущен|Убедись, что окно терминала открыто и нет ошибок красным цветом.|
|`ModuleNotFoundError`|Не установлена библиотека|Введи в терминал `pip install pyTelegramBotAPI`.|
