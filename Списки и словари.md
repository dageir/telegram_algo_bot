## 1️⃣ Списки (List) — `[]`

**Список** — это упорядоченный набор элементов. Как список покупок.

### Создание:

```python 
# Пустой список
my_list = []

# Список с элементами
fruits = ['яблоко', 'банан', 'апельсин']
numbers = [1, 2, 3, 4, 5]
```

### Обращение к элементам:

```python
fruits = ['яблоко', 'банан', 'апельсин']

print(fruits[0])  # яблоко (первый элемент)
print(fruits[1])  # банан
print(fruits[-1]) # апельсин (последний элемент)
```

> ⚠️ **Важно:** Нумерация начинается с **0**!

### Основные операции:

```python
fruits = ['яблоко', 'банан']

fruits.append('груша')      # Добавить в конец
fruits.remove('банан')      # Удалить элемент
len(fruits)                 # Узнать длину (сколько элементов)
'яблоко' in fruits          # Проверить наличие (True/False)
```

### Перебор списка (цикл for):

```python
fruits = ['яблоко', 'банан', 'апельсин']

for fruit in fruits:
    print(fruit)

# Вывод:
# яблоко
# банан
# апельсин
```

## 2️⃣ Словари (Dictionary) — `{}`

**Словарь** — это набор пар «ключ : значение». Как реальный словарь: слово → определение.

### Создание:

```python
# Пустой словарь
my_dict = {}

# Словарь с данными
person = {
    'name': 'Анна',
    'age': 25,
    'city': 'Москва'
}
```

### Обращение к значениям:

```python
person = {'name': 'Анна', 'age': 25, 'city': 'Москва'}

print(person['name'])  # Анна
print(person['age'])   # 25
```

### Изменение и добавление:

```python
person['age'] = 26           # Изменить значение
person['job'] = 'Разработчик'  # Добавить новую пару
```

### Безопасное получение:

```python
person.get('name')     # 'Анна'
person.get('phone')    # None (не вызовет ошибку)
person.get('phone', 'Не указан')  # 'Не указан' (значение по умолчанию)
```

### Перебор словаря:

```python
person = {'name': 'Анна', 'age': 25, 'city': 'Москва'}

# Только ключи
for key in person:
    print(key)

# Ключи и значения
for key, value in person.items():
    print(f'{key}: {value}')

# Вывод:
# name: Анна
# age: 25
# city: Москва 
```

---

## 3️⃣ Главное отличие

|Списки `[]`|Словари `{}`|
|---|---|
|Элементы по номеру (0, 1, 2...)|Элементы по ключу ('name', 'age'...)|
|`fruits[0]`|`person['name']`|
|Порядок важен|Ключи уникальны|
|Для последовательностей|Для структурированных данных|

## 4️⃣ Вложенные структуры

Списки и словари можно комбинировать:

### Список словарей:

```python
users = [
    {'name': 'Анна', 'age': 25},
    {'name': 'Борис', 'age': 30},
    {'name': 'Вика', 'age': 22}
]

print(users[0]['name'])  # Анна
print(users[1]['age'])   # 30
```

### Словарь со списками:

```python
group = {
    'name': 'Python-группа',
    'students': ['Анна', 'Борис', 'Вика']
}

print(group['students'][0])  # Анна
```
